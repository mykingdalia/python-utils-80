# python-utils-80: Autoclicker Tool

Python-utils-80 is a lightweight autoclicker built in Python, designed for automating mouse clicks with customizable frequency and duration. This tool is especially useful for repetitive tasks where manual clicking becomes tedious and time-consuming.

## Features
- **Custom Click Frequency**: Control the speed of clicks, adjusting between milliseconds for precise automation.
- **Start/Stop Functionality**: Easily start and stop the clicking process with keyboard commands for improved user control.
- **Area Selection**: Option to define which screen area should receive clicks, ensuring that the tool operates only where needed.
- **Cross-Platform Compatibility**: Runs seamlessly on Windows, macOS, and Linux, making it accessible to a wide range of users.

## Installation

To get started with python-utils-80, you will need Python 3 installed on your machine. Follow these commands in your terminal:

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/python-utils-80.git
   ```
   
2. Navigate to the project directory:
   ```bash
   cd python-utils-80
   ```

3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Basic Usage Example

After installation, you can start the autoclicker by running the script with the command below. This example starts clicking every 100 milliseconds at the current mouse position:

```python
python autoclicker.py --clicks-per-second 10
```

Simply stop it using the designated keyboard shortcut (Esc by default). For detailed usage, refer to the [Wiki](https://github.com/yourusername/python-utils-80/wiki).
